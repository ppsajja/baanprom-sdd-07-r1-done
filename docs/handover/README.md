# เอกสารส่งมอบ R1 บ้านพร้อม

ส่งมอบพร้อมการลงนามรับ R1 รอบสอง (docs/acceptance/acceptance-record-r1.md 16 พ.ย. 2569) รุ่นที่ส่งมอบคือ Baseline B5 (docs/srs/baseline.md)
ผู้รับ: Ops lead (ระบบและการปฏิบัติการ) หัวหน้า call center และ SH-06 (การใช้งาน) Finance (รายการเงินคืนที่ต้องตาม)

## รายการเอกสาร

| เอกสาร | ไฟล์ | ผู้ใช้ |
|---|---|---|
| คู่มือผู้ใช้สั้น (ลูกค้า ช่าง call center) | docs/handover/user-guide.md | ผู้สอนในการอบรม call center ช่าง |
| คู่มือติดตั้งและตั้งค่า (ตัวแปรแวดล้อม PostgreSQL ช่อง now= ที่ถูกเพิกเฉย /docs ที่ปิด ผู้ช่วยที่ต้องปิด) | docs/handover/install-guide.md | Ops lead ผู้ดูแลเครื่อง |
| คู่มือรับมือเหตุ (runbook) เหตุการณ์ที่ 1 ถึง 6 สำรองและกู้คืน บัญชี endpoint แผนเก็บหลักฐาน | docs/srs/operations.md (ไม่ทำสำเนา ใช้ไฟล์เดียว) | คนเวร Ops lead |

| เกณฑ์ก่อนเปิดให้ลูกค้าจริง และแผน hypercare 2 สัปดาห์ | docs/handover/hypercare-and-golive.md | SH-01 Ops lead RE lead |

## ตรวจว่าส่งมอบครบ (บทเสริม หัวข้อ 6.3)

| รายการ | สถานะ |
|---|---|
| ระบบรุ่นที่รับ (commit ที่ลงนาม) และวิธีสร้างจากของที่ส่งมอบ | มี คู่มือติดตั้งขั้นที่ 2 และ 6 ผ่านการทำจริงใน OAT-1 |
| test ทั้งชุดและผลรันล่าสุด | มี specs/000-shared/test-run.txt |
| คู่มือผู้ใช้ | มี ยังไม่ได้ตรวจกับผู้ใช้จริง (ทำในการอบรมก่อนเปิดใช้) |
| คู่มือรับมือเหตุ | มี รุ่น 1.2 เหตุการณ์ที่ 1 ถึง 5 เดินแล้ว เหตุการณ์ที่ 6 เดินเฉพาะการปิดผู้ช่วย (OAT-7) |
| ข้อมูลตั้งต้นของระบบจริง | ยังไม่มี ไม่มีหน้าจอหรือ REQ สำหรับเติมตารางเวลาของช่าง เป็น transition requirement เสนอใน TOR ของ R2 |
| สิ่งที่ยังเป็นของจำลองและผู้รับผิดชอบเปลี่ยน | มี mocks-and-limits.md |
| เกณฑ์ก่อนเปิดใช้จริงและทางถอย | มี hypercare-and-golive.md ส่วน 1 |
| การอบรม | ยังไม่ทำ มีเกณฑ์วัดในคู่มือผู้ใช้ |
| ผู้รับงานต่อหลังจบ hypercare | Ops lead (ระบบ) RE lead (requirement ที่ตามมาจากหลักฐานการใช้จริง) |
